## 🚀 About This Repository

This repository is dedicated to clean, Pythonic implementations of core computer science data structures and algorithms. Python's readable syntax makes it an excellent language for understanding the underlying logic of complex structures.

## 📂 Contents

Currently included in this repository:

| Structure / Concept | File | Description |

| **Singly Linked Lists** | `5.py` | Node-based dynamic data structure with efficient insertions and deletions. |

*(More structures and algorithms are constantly being added!)*

## 💻 How to Run

You can run these scripts directly using any Python 3 environment.

```bash
# Example: Running the Static Array implementation
python 2.py
```
